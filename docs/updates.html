The milestones.

The releases that changed what Coxpit is. Each links to its full notes on GitHub.

v5.02026·08·20

The console redesign

The left rail became a navigator — a scannable repo list with live run counts and board scoping. Launching moved into a focused New sheet. Dark-themed controls, a compact dry/real switch, a pinned rail. Mobile is drawer-nav plus a compose sheet.

Release notes →
v4.82026·08·20

Exposure-aware auth + an icon system

Access-key authentication that knows where it's bound — loopback stays open for zero-friction local use, a public bind requires a key. Plus a unified Lucide icon set across the board.

Release notes →
v4.0–4.72026·08·19–20

Reach, contracts & the converge workroom

Agents that spawn their own sub-agents, GitHub issue/PR import, read-only share links, the group-band logbook, deliverable contracts with real viewers, and a converge workroom to review, steer and merge a swarm.

Release notes →
v3.x2026·08·18

Runs became workrooms — and a real terminal

A run stopped being one-shot and became a workroom you live in. A full-screen terminal with tmux session tabs, CJK-safe input, Codex as a second provider for mixed fleets, doc-mode review, and the pocket board for your phone.

Release notes →
v2.x2026·08·18

The desktop app & the fleet

A signed, notarized desktop app that embeds the daemon, release CI with installers for every OS, and the ideas that make it a fleet — swarm integration, plan fan-out, and an AI review judge.
