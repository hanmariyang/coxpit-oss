## 0. 목표 / 범위

폰에서 두 가지가 안 된다. ① 터미널에서 **줄바꿈된 긴 링크·명령어를 손으로 못 집는다** ② **긴 답변을 스크롤로 읽기가 괴롭다**. 현재 "뷰어"(모바일 입력바 `#histBtn` → `#histModal`)가 스크롤백을 `<pre>` 텍스트 **한 덩어리**로 부어서 링크·줄복사·검색·읽기폭이 전부 없는 게 원인.

**이 작업 = `#histModal` 을 재빌드한다.** 새 기능 아님, 기존 뷰어 개선.

- **건드리는 파일**: `src/cockpit.ts`(뷰어 모달의 마크업·CSS·JS) · `test/e2e.sh`(체크) · `DESIGN.md`(컴포넌트 표, 같은 커밋).
- **절대 안 건드림**: xterm 터미널(입력용 그대로) · 서버 라우트(`/api/runs/:id/scrollback`·`/chat` 재사용, 무변경) · `src/board.ts`·`src/hud.ts`·`src/login.ts`.
- **의존성 0 · 서빙 HTML만 · coxpit 모노/다크 토큰만**(새 hex 금지, 래칫 cockpit 46 유지).

## 3. UI 스펙

### 3.1 헤더 툴바 (`.pick-h` 확장)

좌→우: `#histTitle` · `.hist-modes`(대화/터미널) · **`#histWrap`(↵ 줄바꿈 토글)** · **`#histFind`(⌕ 검색)** · **`#histJump`(↕ 맨위/맨아래)** · `#histRefresh`(↻) · `#histClose`(×). 새 버튼은 `.hv-btn`(모노 글리프, `.on` 상태는 `--brand`). 좁은 폭에서 넘치지 않게 `.pick-h`를 `flex-wrap:wrap` 또는 아이콘만.

허용 글리프(전부 이모지 게이트 밖 — 확인됨): `↵ U+21B5` · `⌕ U+2315` · `↕ U+2195` · `⧉ U+29C9` · `⊙ U+2299` · `↻ U+21BB` · `× U+00D7` · `↓ U+2193`. **이모지 금지(1F000–1FAFF·2699·26A0·2B50). 서빙 소스 어디에도(주석 포함).**

### 3.2 터미널 탭 — 구조화된 줄 (`#histBody <pre>` → `#histLines` 컨테이너)

`histBody`의 `textContent` 덤프를 폐기하고, `text`를 `\n`으로 쪼개 줄마다 DOM을 만든다:

```
<div class="hln">
  <span class="hln-tx">…linkify된 내용…</span>
  <button type="button" class="hln-cp" title="이 줄 복사">⧉</button>
</div>
```

- **linkify(txt)** — `esc(txt)` 후 두 종류를 감싼다:
  - URL(`/https?:\\/\\/[^\\s]+/`) → `<a class="hln-url" data-url="…">…</a>` (기본 동작 막고 탭 처리, §4).
  - 경로(줄 안의 `~/…`·`/…`·`./…`·`src/x.ts:12` 꼴; 터미널 링크파이어(≈1536)의 규칙과 정합. URL과 겹치면 URL 우선) → `<span class="hln-path" data-path="…">…</span>`.
  - ⚠️ **template literal 이스케이프**: cockpit.ts는 서빙 HTML 문자열이라 클라 정규식의 백슬래시는 **이중**(`\\/`, `\\s`, `\\d`). README #1. 어기면 클라 전체 SyntaxError(스크린샷/`node --check` 파스 체크가 잡음).
- **줄 복사**: `.hln-cp` 탭 → `copyText(원문줄, '줄 복사됨')`. 줄 배경 탭(링크/경로 위가 아닐 때)도 같은 동작(모바일에서 작은 ⧉ 조준 어려움 대비). 원문줄 = linkify 전 텍스트(줄바꿈 무관 논리적 한 줄).
- **네이티브 선택**: `.hln-tx{user-select:text;-webkit-user-select:text}` — 길게 누르면 OS 선택. 줄 배경 탭복사와 충돌하지 않게, 탭 핸들러는 `touchstart`→`touchend` 사이 이동/시간이 임계 이하일 때만(짧은 탭). 드래그/롱프레스는 통과시켜 선택되게.
- **CSS**: `.hln{display:flex;gap:8px;padding:2px 11px} .hln:active{background:var(--surface)} .hln-tx{flex:1;font-family:...mono;white-space:pre-wrap;word-break:break-all;user-select:text} .hln-cp{flex:0 0 auto;color:var(--faint);background:none;border:0}`. `.hln-url{color:var(--running);text-decoration:underline} .hln-path{color:var(--brand);text-decoration:underline}`.

### 3.3 대화 탭 — 읽기 (renderTurn 개선)

- 버블은 유지하되 **선택 가능**(`.ch-bubble{user-select:text}`) + 읽기 리듬(줄간격 1.7 근처, `word-break:keep-all` 한글).
- 답변 본문의 **코드펜스(```…```)** 를 `.hln-code`(모노, `overflow-x:auto`, `white-space:pre`, 우상단 `⧉ 복사`)로 렌더. 나머지 텍스트는 링크·경로 linkify 적용.
- `renderTurn`이 `esc`한 뒤 linkify/코드 처리 — 순서 주의(esc 먼저, 그다음 마커 치환).

### 3.4 검색 (`#histFind` ⌕)

- 탭 → 헤더 아래 `.hist-findbar`(입력 + `n/m` 카운트 + prev/next `‹ ›`) 토글. 활성 표면(터미널 줄 또는 대화)에서 대소문자 무시로 매치, `<mark class="hl">`로 감싸고 현재 매치로 스크롤. Enter/next = 다음, prev = 이전, esc = 닫고 하이라이트 제거.
- 순수 클라(가져온 텍스트 위). 재렌더 시 하이라이트 재적용은 필요 없음(검색 열렸을 때만).

### 3.5 이동 (`#histJump` ↕) + 최신 FAB

- `#histJump` 탭 → 활성 표면이 맨아래 근처면 맨위로, 아니면 맨아래로(토글).
- 표면을 맨아래에서 위로 스크롤하면 `.hist-fab`(↓, 우하단, `--brand`) 표시 → 탭하면 맨아래. 맨아래 근처(임계 40px)면 숨김.

### 3.6 줄바꿈 토글 (`#histWrap` ↵)

- 기본 = 줄바꿈(읽기). 켜면 `.hlines.nowrap .hln-tx{white-space:pre;overflow-x:auto;word-break:normal}` (명령어를 한 줄로 옆 스크롤). 대화 탭에선 코드블록에만 영향(산문은 항상 줄바꿈). 상태 `localStorage 'coxpit.histwrap'` 유지.

### 3.7 새 답변 배지 (P2 · 선택) — 자동열기 대신

**결정: 모바일에서 답변 정착 시 뷰어를 자동으로 열지 않는다**(모달 급습 방지). 대신 포커스된 run이 정착(done)하면 `#histBtn`에 작은 점 배지(`•`, `--brand`)를 붙이고, 뷰어를 열면 지운다. 자동열기를 원하면 이 배지 로직을 `openHistory()` 자동 호출로 바꾸면 됨(플립 지점 1곳). **P0/P1 먼저 완성하고 시간 남으면.**

## 4. 링크·경로·복사 규칙 (한 곳에)

| 대상 | 탭 | 길게 누르기 |
|---|---|---|
| URL(`hln-url`) | `copyText(url,'링크 복사됨')` (기본; 여는 건 별도 아이콘 or 롱탭 메뉴는 P2) | 네이티브 선택 |
| 경로(`hln-path`) | `openPathFromTerm(rid, path)` → 파일 뷰어 | 네이티브 선택 |
| 줄 배경/`⧉` | `copyText(줄원문,'줄 복사됨')` | 네이티브 선택 |
| 코드블록 `⧉` | `copyText(코드,'복사됨')` | 네이티브 선택 |

- URL 탭 기본을 "복사"로(모바일에서 새 탭 급습보다 복사가 안전). 여는 동작은 P2(작은 ↗ 아이콘).
- 탭 vs 롱프레스 판별: `touchstart` 좌표·시각 기록 → `touchend`가 250ms 이내 & 이동 10px 이내면 "탭"으로 처리(preventDefault 최소화, 선택 방해 금지). 마우스(데스크톱)는 `click`으로.

## 5. 함정·규약 (README 반영)

1. **template literal 이스케이프**: 클라 정규식/문자열 백슬래시 이중(`\\/`·`\\s`·`\\d`·`\\n`). 개행 리터럴은 `\\n`. 어기면 served cockpit JS 전체 파스 실패.
2. **이모지 절대 금지**(주석 포함) — 게이트 blacklist 1F000–1FAFF·2699(⚙)·26A0(⚠)·2B50(⭐). §3.1 글리프만.
3. **디자인 래칫**: 새 hex 0. `var(--토큰)`만. cockpit 46 유지(넘기면 e2e 실패 — 토큰으로 해결, 정 필요하면 DESIGN.md 확장+기준선 같은 커밋). 상태색은 기존 토큰(`--running`·`--brand`·`--blocked`·`--done`·`--failed`) 재사용.
4. **e2e 마커는 파일 순서**. JSON은 **node**로(python 금지). 큰 변수는 `case "$V" in *'pat'*`(printf|grep -q 금지, SIGPIPE).
5. **typecheck 필수**: tsx e2e는 타입구멍 못 봄 — 머지 전 `npm run typecheck` 0에러 확인.
6. `[hidden]{display:none!important}` 전역 가드 존재 — 표시 토글은 클래스/`hidden`으로.

## 9. 실기기 수정 (owner 폰 테스트 — "쓸모없다" 두 건)

- **터미널 탭이 지금 화면만 보였다.** 원인 둘: coxpit tmux 세션이 기본 `history-limit`(2000)으로 떴고, 캡처가 `-S -N` 범위였다. 수정 — 세션 생성은 전부 `tmuxNewSession()`(orchestrator) 하나로: 같은 tmux 호출 안에서 `start-server ; set-option -g history-limit 100000 ; new-session`. **history-limit 은 pane 이 태어날 때 값이 고정**이라 new-session 뒤에 세션 옵션으로 올리면 첫 pane 에는 안 먹는다. 캡처는 `capture-pane -S -`(히스토리 전체) 후 node 에서 꼬리 N 줄(클라이언트 2만 줄 — 폰 DOM 보호).
  - 한계(버그 아님): 전체 화면 TUI(claude CLI·vim·less)는 tmux **대체 화면**을 써서 스크롤백이 없다 — 떠 있는 동안은 보이는 화면뿐. 헤드리스 에이전트 run 의 tmux 는 비어 있는 게 정상이고 볼 곳은 "대화" 탭.
  - 주의: `set-option -g` 라 같은 tmux 서버의 이후 새 pane 에도 10만 줄이 적용된다(데몬이 기본 서버를 쓰는 경우 사용자의 다른 세션 포함).
- **뷰어가 폰에서도 가운데 작은 팝업이었다.** 데스크톱 크기를 인라인 `style` 에서 `.hist-pick` CSS 로 옮기고(인라인이면 `!important` 없이 못 덮는다), `body.touch` + `@media (max-width:860px)` 에서 `#histModal .hist-pick` 을 `position:fixed; inset:0; 100%×100%; border-radius:0` + safe-area 패딩으로. 줄·대화 영역은 `min-height:0` 이라 시트를 밀지 않고 자기가 스크롤한다. 데스크톱은 가운데 팝업 그대로.
